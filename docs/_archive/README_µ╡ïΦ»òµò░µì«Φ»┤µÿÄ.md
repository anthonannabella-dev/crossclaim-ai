## 一、DeepSeek 实跑验证（最关键）

你的 key **已经配置好**（`.env` 和 `backend/.env` 都有，`sk-` 开头 35 位，格式正确）。
我在沙箱里没法替你真调（出网受限、也不该用你的 key），所以给你一个**一键自检脚本**：

```bash
# 放在项目根或 backend 目录都行（Node 18+，无需装包）
node verify_deepseek.js
```

它会依次告诉你：
- ✓ 能不能读到 key（以及读的是哪个 .env）
- ✓ 能不能连上 api.deepseek.com（网络层）
- key 是否有效 / 余额是否充足（401=key无效，402=余额不足，429=限流）
- ✓ 真跑一次「智能归类」，打印 AI 返回 + token 用量

任一步失败都有明确中文提示。**这一步通过，就证明 AI 功能（智能归类/退单诊断/预检补充）在你的环境真能用。**

> ⚠️ 安全：这个 key 已经在压缩包里明文传过了，建议到 DeepSeek 控制台**重置**一次再用；
> 并给 `.gitignore` 补上 `.env`（你项目的 .gitignore 现在是空的，有泄露风险）。

## 二、测试数据从哪来

**别在淘宝/闲鱼买真实单证数据。** 真实报关单据含企业商业秘密+个人信息，买卖有法律风险、来源多为泄露。正确两条路：

1. **自有数据脱敏**：你是货代/报关，手里有真单据——把真实公司名/税号/金额替换成假值即可测。
2. **合成测试数据**：用 `sampledocs/` 里这套——我**按系统的字段解析规则**造的，能被 OCR 解析、能跑通核对+制单。

### sampledocs/ 里的样本（已验证可解析、字段互相对得上）

| 文件 | 用途 |
|---|---|
| 01_商业发票_CommercialInvoice.pdf | 制单核心（HS/品名/数量/单价/金额/币制/成交方式/原产国）|
| 02_装箱单_PackingList.pdf | 件数/毛重/净重/体积/唛头 |
| 03_提单_BillOfLading.pdf | 提单号/船名航次/装卸港/箱封号/毛重/收货人 |
| 04_外贸合同_SalesContract.pdf | 合同号/买卖双方/金额/成交方式 |
| 05_问题装箱单_PackingList_BAD.pdf | **反例**：毛重/数量/HS/收货人故意不一致，用来测「核对能抓出问题」|

**关键字段（01-04 一致，交叉比对会全过）**：
- 提单号 COSCO5582147；发票号 INV-2024-0617；收货人 ACME TRADING LLC
- HS 8517120000 / 8504401400；数量 1000 PCS；毛重 3200.50 KGS；净重 2950.25 KGS
- 币制 USD；成交方式 FOB；原产国 CN；总额 48650.00 USD

### 怎么用（验证整条流水线）
1. 进「自动化报关 / 提单核对」，把 **01~04 四份**作为同一提单（COSCO5582147）上传。
2. 跑「提单核对（交叉比对）」→ 4 项应**全部一致**（HS、数量[发票↔箱单]、毛重[箱单↔提单]、收货人）。
3. 跑「自动化报关」流水线 → OCR→AI校验→制单→预检→导出 XML，看能否生成报关单 XML。
4. 反例验证：用 01+03+**05(问题装箱单)** 重跑核对 → 应**标红**毛重/数量/HS/收货人不一致。

> 解析已离线验证：用系统的正则跑过，发票号/数量/毛重/提单号/收货人/HS 都能正确抽出。
> 实际 OCR 识别率仍取决于你环境的 tesseract/pdf-parse，建议先用这套干净 PDF 打通链路。

## 三、一票出口报关需要哪些单（"一个提单不够"）

**最低要：商业发票 + 装箱单 + 提单**（否则制单抽不到 HS/品名/价格，核对也没有对照单）。

### A. 每票必备（核心6项）
1. 运输单据：海运提单 B/L / 空运单 AWB / 铁路运单
2. 商业发票（制单核心）
3. 装箱单
4. 外贸合同
5. 报关委托书（委托货代/报关行时）
6. 申报要素（品名/品牌/规格型号/用途/材质/成分…）

### B. 按商品/监管按需
7. 出口许可证 / 两用物项许可证 → 可在「证件台账」登记预警
8. 原产地证书（CO / FORM A·E / RCEP）
9. 法检：出境货物通关单、品质证书、卫生/植物检疫/熏蒸证书
10. 3C 强制性认证（如适用）
11. 危险品：MSDS、危包证、海事申报
12. CIF/CFR 成交：运费发票、保险单
13. 濒危物种证等特殊监管证件

### C. 跨境电商专属（三单对碰）
14. 订单单（电商平台）15. 支付单（支付企业）16. 物流单（物流企业）— 9610/1210/1239
17. 9710：B2B合同/订单；9810：海外仓入仓单/备案

### D. 退税专属
18. 增值税专用发票（供应商发票，进项）19. 出口收汇/结汇凭证

> 系统现状：OCR 分类器只认 6 类（发票/装箱单/提单/原产地证/报关单/合同）。
> 报关委托书、跨境电商三单、法检通关单、MSDS 暂无专门识别类型（三单当字段录入、许可证走证件台账）。
> 如需，可把 OCR 单证类型扩到覆盖三单+报关委托书，并补进交叉比对。
