# Customs / Broker Limitation（报关与代理限制）

> documentKey: `customs-broker-limitation`。

- CrossClaim **不是**持牌报关代理，也**不是**律所；不提供个案法律意见。
- CrossClaim 可以：审计、归类辅助、证据准备、生成 claim-ready package。
- 需要持牌代理或由客户自行提交的场景：明确披露并由客户决定；CrossClaim 不代替客户提交受监管申报。
- 退款资金默认指向客户/索赔人的合法账户；CrossClaim 默认**不代收**、不形成资金池、不从退款中截留佣金。
