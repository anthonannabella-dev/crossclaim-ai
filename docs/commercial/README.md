# Commercial / Legal content layer（PC-09）

本目录是 CrossClaim 面向客户的**商业/法律披露**内容层。

- 版本与状态的唯一机器可读来源：`apps/api/src/services/commercial/policy-registry.ts`
- 本目录只承载人类可读正文；registry 通过 `documentRef` 指向对应文件。
- **非法律意见**：本层只做披露与接受事实留痕，不提供个案法律意见。
- 真实付款（Payment = 0 / collection = OFF）、真实 provider 授权（EXTERNAL_GATE）与对外提交仍为 HOLD。
