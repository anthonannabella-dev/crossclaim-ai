# Recovery Service Scope（追回服务范围）

> documentKey: `recovery-service-scope`。

- **包含**：数据接入与对账、机会发现、证据整理、申请包（claim-ready package）准备、状态跟踪、人工提交指引。
- **不包含**：代替客户作出法律决定；代替持牌代理提交受监管申报；代收客户款项或形成资金池。
- **人工环节**：对外提交在 HITL 与 Action Guard 约束下进行；当前对外通道 `TRANSPORT=false`。
- **结果说明**：CrossClaim 不承诺特定追回结果；estimate 不等于 actual recovered。
