# C-0009.1 Validation Runs

用途：登记每一次真实/脱敏真实结构的验证运行（架构方 MSG-20260928-68 REVISE-2）。**不需要 Schema 变更**，仅报告文件。

规则：
- 每个 run 一个 `VALIDATION-RUN-NNN` 编号（从 001 开始，单调递增）。
- 未登记 run 之前，商业验证状态一律 `OPEN`（工程样例不算商业验证）。
- 输入文件只登记 **sha256 与行数**，不登记客户名/账号/运单号/合同原文。

## 模板

```text
VALIDATION-RUN-NNN
date:               (ISO 时间)
input:              (文件名 + sha256 + 行数)
inputKind:          (desensitized-real-structure | real-customer-approved)
channel:            (UPS / FedEx / DHL / …)
customerType:       (seller | forwarder | other，可匿名)
importBatchId:      (若适用)
opportunitiesOut:   (产出机会数)
recoverableTotal:   (产出可追回金额合计，Decimal 4 位)
customerFeedback:   (有价值 / 无价值 / 金额不可信 / 需要哪些字段 + 原话摘要)
decision:           (CONTINUE | PAUSE | KILL)
notes:              (人工转换/字段映射等说明)
```
